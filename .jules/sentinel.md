## 2024-05-24 - [Timing Attack in Secret Comparison]
**Vulnerability:** The scheduler secret in `backend/src/routers/internal.py` was being compared using a simple inequality operator `!=`, which is vulnerable to timing attacks. This allowed an attacker to potentially deduce the secret character by character based on the response time. Additionally, error handling in both `internal.py` and `portfolio.py` exposed internal exception details (`detail=str(e)`) to the client, leading to information disclosure.
**Learning:** Python's standard equality operators perform short-circuiting comparisons, which take less time when the strings differ early on. Always use constant-time comparison functions for secrets. Furthermore, never expose raw exception strings in HTTP error responses, as they may leak sensitive backend structure or data.
**Prevention:** Always use `secrets.compare_digest()` for comparing security tokens, passwords, or secrets. Ensure to handle potential `None` values (e.g., missing headers) before calling `compare_digest()`. Log raw exceptions internally but return generic, sanitized error messages to the client.
