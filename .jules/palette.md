## 2024-05-20 - Icon-Only Button Accessibility in Reusable Components
**Learning:** Generic, reusable UI components (like Dialogs or Modals) often contain icon-only buttons for actions such as closing or dismissing. When these components lack `aria-label`, proper `type="button"`, and explicit focus visibility states, it significantly degrades the experience for screen reader users and keyboard navigators across the entire application where the component is used.
**Action:** When implementing or modifying reusable UI components containing icon-only interactive elements, ensure they explicitly set `type="button"` to prevent unintended form submissions, provide a clear descriptive `aria-label`, and include focus styles (e.g., `focus-visible:ring-2`) to ensure keyboard navigability and screen reader support.
