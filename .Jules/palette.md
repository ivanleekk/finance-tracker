## 2026-05-06 - Input Accessibility Improvements\n**Learning:** The existing Input component lacked proper ARIA attributes to connect helper text and error states with the input element, which makes it harder for screen readers to understand the form state. Adding `aria-invalid` and `aria-describedby` attributes provides essential context without changing the visual design.\n**Action:** Always ensure that dynamically generated IDs are linked properly to helper texts, and that error states are semantically communicated using `aria-invalid`.
